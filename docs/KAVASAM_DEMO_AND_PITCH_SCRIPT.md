# KAVASAM DEMO AND PITCH SCRIPT

## Goal

Create a powerful 5-minute hackathon demonstration.

------------------------------------------------------------------------

# Opening

Problem:

"Millions of people lose money not because they cannot report fraud, but
because nobody protects them during the few minutes when fraud happens."

------------------------------------------------------------------------

# Demo Scenario 1: Digital Arrest Scam

Actor:

Scammer pretending to be CBI officer.

Flow:

1.  Fake call arrives.
2.  User activates KAVASAM suspicious call mode.
3.  AI detects scam patterns.
4.  Voice warning appears in Tamil.
5.  Guardian receives alert.

Judge sees:

AI detection + language accessibility + family protection.

------------------------------------------------------------------------

# Demo Scenario 2: Fake QR Payment

Flow:

1.  User scans suspicious QR.
2.  KAVASAM extracts payment details.
3.  AI checks context.
4.  Warning appears.

Message:

"This payment destination appears suspicious."

------------------------------------------------------------------------

# Demo Scenario 3: Fraud Message

Flow:

1.  User shares SMS.
2.  AI generates risk score.
3.  Explanation shown.
4.  User understands why.

------------------------------------------------------------------------
